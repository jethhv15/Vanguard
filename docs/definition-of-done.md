# Definition of Done

A task is considered complete only if all requirements below are satisfied.

## Code Quality

- [ ] Code follows Project Vanguard coding standards.
- [ ] No unnecessary complexity is introduced.
- [ ] Public APIs remain backward compatible.

---

## Testing

- [ ] Existing tests pass.
- [ ] New functionality includes appropriate tests.
- [ ] No known regressions remain.

---

## Documentation

- [ ] Documentation has been updated.
- [ ] API reference reflects the implementation.
- [ ] Architecture documentation remains accurate.

---

## Review

- [ ] Code has been reviewed.
- [ ] Commit message follows the project convention.
- [ ] No unresolved review comments remain.

---

## Release Readiness

- [ ] CHANGELOG updated (if applicable).
- [ ] Version updated (if applicable).
- [ ] Ready to merge.
